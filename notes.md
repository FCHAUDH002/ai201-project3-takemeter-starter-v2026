# Milestone 1: community and candidate distinctions

Community: r/college (www.reddit.com/r/college/)

1. Some comments offer the poster something to do. Most only give a verdict.
2. Some comments back a claim with something specific others could check. Most rest on feeling.
3. Some comments tell a concrete first-person story. Most don't.
4. Some comments only react or agree. Most make a claim.
5. Some comments ask the poster a question instead of answering.
